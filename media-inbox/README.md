# Media inbox — drop your files here

Put new files in the matching folder, then tell Claude Code:
"Add the new files from media-inbox."

| Folder | Put here |
|---|---|
| photos/ | Photos and images (JPG, PNG) — competition photos, moments, project covers |
| videos/ | Short video clips — or just paste a YouTube/Google Drive link to Claude Code |
| documents/ | PDFs: proposals, reports, posters |
| slides/ | PowerPoint (.pptx) presentations |
| certificates/ | Award and course certificates |
| wallpapers/ | Your own landscape / engineering-wonder photos to replace a section background |

Tip: name files clearly, e.g. `UAiTED-2024-team-photo.jpg`, so Claude knows which project they belong to.
Nothing in this folder goes online — only what Claude moves into the website.
