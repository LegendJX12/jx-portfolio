# PRD — JX Portfolio Website

## Value proposition
One place that shows who JX is as an engineer and innovator — richer than LinkedIn, with the
real proposals, slides, videos and certificates behind each achievement.

## Target audience (ICP)
- Recruiters and hiring managers in Singapore and Malaysia (engineering consultancies,
  defence/security, infrastructure, energy, climate tech).
- Competition judges, start-up partners, investors and collaborators.

## Pain points it solves
- LinkedIn hides attached media and long descriptions behind clicks.
- No single, shareable link that tells the full story with files.
- Updating a portfolio must be easy for a non-coder.

## Pages (v1)
1. **Home** — hero, stats, About, Experience, featured achievements, Education,
   Certifications (show 6 / show all), Skills, Languages, Leadership, Contact.
2. **Achievements** — all honours with filter by theme (Coastal & water, Health tech,
   Digital & AI, Structures, Academic).
3. **Project detail** (template, one per project) — tabbed media viewer
   (Video / Slides / PDF / Gallery), key numbers, team, SDGs, downloads, prev/next.

## Must-haves
- Adding a new project = add one Markdown file + its media folder. No code changes.
- Works great on mobile.
- Fast: Lighthouse performance ≥ 90.
- "Download CV" button (PDF).

## Later (v2 ideas)
- GitHub projects pulled automatically.
- Contact form.
- Blog / notes.
