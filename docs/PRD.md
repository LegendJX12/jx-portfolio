# PRD — JX Portfolio Website

> Updated 2026-10-12: personal portfolio that mainly features projects and life
> (competitions, Dean's List, Munich exchange, CCA, sports). No CV download.

## Value proposition
One place that shows who JX is as an engineer and innovator — the real proposals, slides,
videos and photos behind each project, plus the moments around them.

## Target audience
- Recruiters and hiring managers in Singapore and Malaysia.
- Competition judges, start-up partners, collaborators, friends.

## Pages (v1)
1. **Home** (structure inspired by sjgroup.com) — hero statement + theme chips,
   Explore my projects (big swipe cards), What I do, Where I've been (MY, SG, DE, TW),
   Moments (photo grid), Contact.
2. **Projects** — all projects with filter by theme (Coastal & water, Health tech,
   Digital & AI, Structures, Academic).
3. **Project detail** (one per project) — tabbed media viewer (Video / Slides / PDF / Gallery),
   key numbers, team, SDGs, downloads, prev/next.

## Must-haves
- Adding a new project = add one Markdown file + its media folder. No code changes.
- Adding a moment (photo) = add one entry, no code changes.
- Works great on mobile. Lighthouse performance ≥ 90.

## Later (v2 ideas)
- More "life" sections as JX decides (sports, travel stories).
- Contact form. Blog / notes.
