# Project files (PDFs, slides, gallery photos)

Make one folder per project, named like the project file, e.g. `public/media/seasiders/`.
Then put the files there with the names listed under `media:` in that project's `.md` file.

- Slides (PPT/PPTX): open in PowerPoint → File → Save As → PDF, then add the PDF.
- Videos: do NOT put video files here. Upload to YouTube or Google Drive and paste the link.
- Max 10 MB per file.
